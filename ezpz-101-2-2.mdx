# Game-pool Mechanism

![Ezpz Game Pool Flow V2](/images/ezpz_game_pool_flow_v2.png "Ezpz Game Pool Flow V2")

For the above flow chart, we will be using the token called \$Catai, (this is just used as an example to explain the entire flow).

1. Once a synthetic market exists, lets say for example once \$Catai launches on [pump.fun](http://pump.fun) and the creator opens a synthetic market for it on EZPZ (per the earlier flow depicting Pillar 1). That market being live is the unlock condition.
2. Games unlock for the token, once the market is present, the "game creation" option becomes available to the creator for \$Catai specifically.
3. Creator chooses from an array of games, selecting initially 1 game from a menu of 3-5 ready made templates.
4. After choosing the game, creator seeds the game POT, this is a separate pool from the synthetic market's own POT. This game POT has to be funded specifically in \$Catai since that is the token the game is running on. Moreover that is the token the creator launched on [pump.fun](http://pump.fun) officially.
5. Users play with \$Catai, anyone who wants to predict against or play the game created by that specific creator has to use \$Catai as that is the currency that is being supplied by the creator for the games
